# Site vitrine Tickami — https://tickami.fr

Pages générées, ne pas modifier à la main : elles sont produites par `2- Livrables/scripts/build_site.py`
(textes dans `2- Livrables/scripts/site_content.py`, CGU et confidentialité tirées des traductions de l'app,
styles et scripts dans `2- Livrables/assets/site/`) :

    python "2- Livrables/scripts/build_site.py" "4- Site public"

Puis commit et push : GitHub Pages publie la branche `main` sur tickami.fr.

Pages : accueil, fonctionnalités, tarifs, FAQ, mentions légales, CGU, confidentialité (FR et `en/`), 404,
`sitemap.xml`, `robots.txt`, images de partage `og-fr.png` / `og-en.png`.
